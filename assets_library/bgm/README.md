# BGM ライブラリ

`video-assembler` がここから台本の雰囲気に合うBGMを1曲選び、ナレーションの下に
-18〜-22dB程度で敷きます（ナレーション区間はサイドチェイン圧縮でダッキング）。

## 置き方

著作権フリー／ライセンス許諾済みの音源のみを置いてください。ファイル名は
`<ムード>_<おおよその尺(秒)>s_<出典/ライセンス略称>.mp3` の形式にすると選定しやすくなります。

例:

```
assets_library/bgm/calm_180s_cc0.mp3
assets_library/bgm/upbeat_240s_cc0.mp3
assets_library/bgm/serious_300s_licensed.mp3
```

ナレーションより短い曲はループされるので、極端に短い曲でも問題ありません
（`scripts/assemble_video.sh` が `-stream_loop -1` でループしてから尺に合わせてトリムします）。

## 出典管理

商用利用・収益化に影響するため、各ファイルの出典・ライセンス条件をこのディレクトリ内の
`SOURCES.md`（任意）などに必ず記録してください。出典不明の音源は `qa-guardian` の
著作権審査で REJECT 対象になります。

このディレクトリ自体（`.gitkeep` 以外）は `.gitignore` で追跡対象外にしています。
実運用では各自の音源をローカルまたは外部ストレージに配置してください。
